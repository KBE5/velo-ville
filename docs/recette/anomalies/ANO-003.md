## Description du problème
Lorsque le serveur API est arrêté, la page Streamlit gère le cas d'erreur mais affiche un message générique plutôt qu'un panneau dédié avec bouton de tentative de reconnexion.

## Erreur attendue vs obtenue
- **Attendu :** Affichage d'un bloc `st.error` structuré avec un bouton de rafraîchissement dédié.
- **Obtenu :** Message d'erreur standard lors de la perte de connexion.

## Cause racine
Gestion centralisée des exceptions HTTP fonctionnelle mais sans bouton d'action directe de ré-essai dans l'IHM.

## Décision / Arbitrage
Fonctionnalité non bloquante. L'interruption d'API étant signalée de manière compréhensible, l'ajout du composant de ré-essai dynamique est **reporté à la maintenance évolutive V1.1**.
